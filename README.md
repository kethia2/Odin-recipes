# Odin-recipes

This project is part of the Odin Project curriculum. It's about using attributes and elements in HTML to built a simple webpage of different Recipes.


## Skills Demonstrated
Creating and structuring a basic HTML boilerplate

Adding and linking images using the `<img>` tag with proper `src` and `alt` attributes

Creating hyperlinks using the `<a>` tag

Organizing project files and directories using the Linux command line
